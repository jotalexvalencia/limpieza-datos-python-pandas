# Limpieza de Datos con Python y Pandas  

## Descripción  
Script para eliminar **outliers** en un dataset de ventas usando el método **IQR (Rango Intercuartílico)**.  
**Casos de uso**:  
- Ideal para analítica financiera o procesos de auditoría.  
- Integración con **AWS S3** para almacenamiento seguro.  

## Tecnologías  
- Python  
- Pandas  
- AWS S3
